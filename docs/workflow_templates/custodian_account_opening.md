# Account opening at the custodian

```json template
{
  "key": "custodian_account_opening",
  "title": "Account opening at the custodian",
  "category": "onboarding",
  "parameters": [
    {
      "name": "custodian_name",
      "label": "Custodian",
      "kind": "text",
      "default": "the custodian",
      "required": true
    }
  ]
}
```

To open an account at a custodian: check the owners in the member's ownership hierarchy, prepare the custodian's account forms, collect signatures, submit the instruction to the custodian, and confirm and record the new account number.

The workflow sends nothing to a custodian; a person submits the instruction.
