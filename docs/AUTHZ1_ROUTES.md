# AUTHZ1 — every API route, its gate before and after

Generated by `apps/api/scripts/authz1_routes.py` from the live app (`main.app`, lazy routers flattened) and the endpoint source (+ same-module helpers). Before = `a911ac7` (pre-AUTHZ1); after = this commit.

**444 routes** = 448 flattened app routes minus 4 docs routes (`/openapi.json`, `/docs`, `/docs/oauth2-redirect`, `/redoc`). **197 writes had no effective gate in production** and are marked [FIND].

Production effect of a before-gate: token-claim helpers allowed when the claim was absent (always, for real tokens); an rbac gate fed `get_user_id` got a uuid5 phantom id with no roles and default-allowed; an rbac gate fed `ensure_user` default-allowed any role-less user. After AUTHZ1 every gate reads the DB Principal (`services.authz`) with no default-allow; every authenticated route additionally requires an admitted account (pending / retired / rejected → 403) except `GET /api/v1/users/me` and `PUT /api/v1/users/me/contact-email` (own row only), and an unresolvable user is a 401.
